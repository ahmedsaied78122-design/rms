# RMS Frappe app

Custom Restaurant and Retail operations app for ERPNext. All custom DocTypes,
controllers, Desk pages, translations and migrations belong here; ERPNext core
DocTypes remain untouched.

The app source targets Frappe/ERPNext 16.50+. It is installed and migrated on
the local Ubuntu 24.04 WSL Bench. Do not migrate to a hosted site until its
installed versions and current customizations are inspected and confirmed.
